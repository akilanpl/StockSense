# StockSense

Inventory management workspace for the Odoo x GCET Hyderabad hackathon.

Phase 1 is the application foundation: Next.js App Router, shared layout, route shells, route handlers, and a Prisma client prepared for PostgreSQL. Inventory models and stock logic are intentionally not included yet.

Copy `.env.example` to `.env` and set `DATABASE_URL` before connecting a database.

```bash
npm install
npm run dev
```
